AI 데이터 자동입력

AI 대화 요약 또는 정형화된 업무 텍스트를 붙여넣고, 미리보기 후 여러 건을 한 번에 등록합니다.
외부 AI API를 호출하지 않습니다. 이 앱은 붙여넣은 텍스트의 항목명과 형식을 기준으로 분리합니다. 자유로운 대화 원문은 먼저 AI 정리 지시문으로 정리한 뒤 결과를 붙여넣는 것을 권장합니다.

등록 전 미리보기

자동 분류 결과를 확인하세요. 업무명·프로젝트·날짜가 잘못 추정되었으면 원본 텍스트를 수정해 다시 분석하는 것이 안전합니다. 중복 가능성이 있는 기록은 표시됩니다.

프로젝트 관리

기본 프로젝트 코드를 기준으로 업무를 분류합니다.

기본 프로젝트는 삭제할 수 없습니다. 사용자 추가 프로젝트는 해당 업무 기록이 없을 때 삭제할 수 있습니다.

설정 및 데이터 관리

데이터는 이 브라우저에 저장됩니다.

데이터 백업 및 복원

업무 기록과 프로젝트 설정을 JSON 파일 하나로 내보내거나 복원합니다.

데이터 초기화

초기화하면 현재 브라우저에 저장된 업무 기록과 사용자 프로젝트가 삭제됩니다. 실행 전 JSON 백업을 권장합니다.

저장 및 보안 안내

  • 저장 위치: 현재 브라우저의 localStorage
  • 브라우저 데이터 삭제·초기화 시 업무 기록이 사라질 수 있습니다.
  • 다른 기기와 자동 동기화되지 않습니다. 기기 간 이동은 JSON 백업 파일을 사용하세요.
  • 민감한 개인정보, 비밀번호, 결제정보는 기록하지 마세요.
  • 이 앱은 외부 서버로 데이터를 전송하지 않습니다.
